# Fast Restart for BO7 Zombies (Kronos)

fast_restart style restart for BO7

* Crouch (or go prone), then pause, the Save & Quit button changes to Fast Restart
* For normal save and quit pause while standing

Only tested solo

Install: Download `FastRestart-1.zip` from [Releases](../../releases), close the game, and copy the `fast_restart` folder into `<game folder>\kronos\mods\`. Keep its `scripts\compiled` folder. Then enable Fast Restart in the Kronos Mods menu. Tested on Kronos 1.41

# Fast Restart for BO7 Zombies (Kronos)

Old-CoD style fast restart for any Black Ops 7 Zombies match on the Kronos client.
By [Tinhorn](https://www.youtube.com/@TheTinhorn) — subscribe :)

- **Crouch (or go prone), then pause:** the pause menu's *Save & Quit* reads **Fast Restart**. Press it and the
  match restarts instantly, no menus or reload.
- **Pause while standing:** the normal *Save & Quit*.

The button label always shows which one you'll get. Host only.

## Install

Download `FastRestart-1.zip` from [Releases](../../releases), close the game, and copy the `fast_restart` folder into
`<game folder>\kronos\mods\`. Keep its `scripts\compiled` folder. Then enable **Fast Restart** in the Kronos Mods menu.
Built and tested on Kronos v1.41.

To get the plain Save & Quit back for good, turn the mod off in the Kronos Mods menu.

## If it doesn't work

Send Tinhorn `<game folder>\poi_reg.log` (lines starting `fast restart:`) and
`<game folder>\kronos\fast_restart\state.json`, copied before starting the game again.
